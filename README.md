# Script Engine

This project is a scaffold for a visual interview script designer built with React, React Flow and Zustand. It provides a minimal setup using Vite and Tailwind CSS.

## Development

1. Install dependencies (requires npm):

```bash
npm install
```

2. Start the dev server:

```bash
npm run dev
```

The app will be available at `http://localhost:3000`.

## Build

To build the project for production:

```bash
npm run build
```

## Project Structure

- `src/` – application source code
  - `components/` – React components
  - `store/` – Zustand store for the interview graph
  - `types/` – TypeScript type definitions
- `index.html` – app entrypoint

This scaffold follows the specification for a life-insurance interview script designer using React Flow.
